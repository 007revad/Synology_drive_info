Static smartctl 7.5 (smartmontools) binaries for Synology routers (SRM 1.3) and NAS (DSM 6, DSM 7)

  smartctl-armv7-hf-static   ARMv7-A, Thumb-2, VFPv3-D16, hard-float
                             RT2600ac (ipq806x), MR2200ac (dakota), WRX560 (hawkeye)
  smartctl-aarch64-static    AArch64
                             RT6600ax (cypress), DS218 (rtd1296)
  smartctl-x86_64-static     x86-64 baseline
  smartctl-i386-static       32-bit x86, i686 baseline

SRM and DSM include smartctl 6.5, which can't read USB NVMe drives. smartctl 7.5 adds the
sntasmedia, sntjmicron and sntrealtek USB-NVMe bridge types. SynoCommunity's SynoCli Disk
Tools is 25 MB and only has smartctl 7 for some platforms only (no cypress or hawkeye).
A smartctl7 from SynoCli Disk Tools in /usr/local/bin is used in preference to these.
These binaries are self-contained: no libraries from the firmware or from another package.
The drive database is built in (7.5, dated 2025-04-27). No drivedb.h file is needed.

HOW THEY WERE BUILT
  build-smartctl.sh (included) cross-compiles the binaries on x86_64 Linux with
  Zig 0.17.0 (clang + musl libc). Statically linked. libcap-ng, SELinux and systemd
  support are disabled. Only smartctl is built, not smartd.
  Running build-smartctl.sh from two different directories gives byte-identical
  binaries:

    6b056368863a8cd5857de53f308016d42f87be30e2159b01d9047411c9563cd9  smartctl-aarch64-static

  TESTED
    armv7-hf  RT2600ac (SRM 1.3.2): runs, smartctl 7.5, reads a USB NVMe drive (RTL9210C) with -d sntrealtek
    aarch64   DS218 (DSM 7.4.1): runs, smartctl 7.5, reads a USB NVMe drive (RTL9210C) with -d sntrealtek
    x86_64    DS1821+ and DS925+ (DSM 7.4.1), DS1812+ (DSM 6.2.4): runs, smartctl 7.5
    i386      Not yet tried on a Synology NAS with evansport CPU
